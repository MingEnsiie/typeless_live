1产品定位 / Vision

Typeless 是一款基于大模型的 AI 语音输入法。用户按住快捷键即可对麦克风说话，系统在后台完成 语音采集 → ASR 转写 → LLM 后处理（去口癖、加标点、风格改写、翻译） → 注入到任意应用焦点输入框 的全链路，实现"动嘴比动手快 4 倍"的输入体验。

⚡ 快

流式 ASR + 增量 LLM，端到端 < 1.5s。本地 Whisper Tiny 离线可用。

🧠 智能

应用上下文感知：邮件 / IDE / IM 自动切换 prompt 与风格。

🔒 隐私

本地模式：录音不落盘、不出本机；密钥使用系统 keyring 加密存储。

2整体架构 / Architecture

架构核心思想： Rust Core 一次实现，平台适配层通过 trait 抽象，桌面端通过 Tauri 暴露 UI，移动端通过 UniFFI/JNI 复用核心逻辑。

8风险与待澄清 / Risks

R1 · API 文档缺失： "DeepSeek V4 Pro" 与 "小米 MiMo Token Plan" 需用户提供官方文档链接，否则按 OpenAI 兼容协议先行实现。
R2 · iOS 键盘扩展限制： 内存 ≤ 60MB、需 Full Access 才能联网，本地大模型可能跑不动；建议主 App + 共享剪贴板折中方案。
R3 · Wayland 注入权限： 部分发行版需要将用户加入 input 组或运行 ydotoold，需在 onboarding 中引导。
R4 · Fcitx5/IBus 跨发行版差异： Ubuntu/Fedora/Arch 版本与依赖差异大，需多 distro CI 测试。
R5 · 隐私合规： 默认本地模式 + 明确同意才上传；keyring 加密；录音不落盘选项。
